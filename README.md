# Weekly Meal Planner & Grocery Generator

## Project Description

The **Weekly Meal Planner & Grocery Generator** is a beginner-friendly Java console application for planning meals across seven days and displaying a categorized grocery list.

The program allows the user to:
- View available meals
- Select a meal for each day of the week
- View the weekly meal plan
- Generate the grocery-list step
- Display a categorized grocery list
- Exit the application

## Technology Used

- Java
- Java `Scanner`
- Arrays
- Loops
- `if-else`
- `switch-case`
- Methods
- Console input/output

## Main Features

### 1. View Available Meals
The program provides seven predefined meal choices:
- Vegetable Rice
- Chicken Rice
- Vegetable Pasta
- Dal and Rice
- Chapati and Curry
- Idli and Sambar
- Vegetable Sandwich

### 2. Select Meals for the Week
The user selects one meal for each day from Monday to Sunday.

### 3. View Weekly Meal Plan
The selected meal for every day is displayed in a simple day-by-day format.

### 4. Generate Grocery List
The program provides a grocery-list generation step and confirms that the list has been generated.

### 5. Display Grocery List
The grocery list is displayed under categories such as:
- Vegetables
- Fruits
- Grains
- Dairy
- Protein
- Other Items

## How to Run

### Step 1: Install Java

Install a Java JDK and make sure `java` and `javac` are available in your terminal.

### Step 2: Compile

Open the repository folder in a terminal and run:

```bash
javac WeeklyMealPlanner.java
```

### Step 3: Run

```bash
java WeeklyMealPlanner
```
